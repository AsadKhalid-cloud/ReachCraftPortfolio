#  ReachCraft — Digital & IT Agency Website

**Build Your Brand. Reach Your Customers.**

Official Full-Stack Website & Custom CMS Admin Panel for **ReachCraft Digital Agency** (Founded by **Asad Khalid, Furqan & Zohaib**).

### Key Features
- **Modern Multi-Page Frontend:** Home, About & Team, Services, Case Studies/Portfolio, Blog, and Contact pages.
- **Interactive Package Estimator:** Clients can build custom service bundles and send quotes directly to WhatsApp.
- **Smart AI Assistant Widget:** Built-in interactive assistant to guide visitors 24/7.
- **Full-Stack Admin Control Center (`admin.html`):**
  - Client Review Approval System (`Pending` ➔ `Approved`)
  - Dynamic Blog Publishing & Reader Modal
  - Portfolio Project Manager with Direct Image Upload (`Multer`)
  - Client Inquiry Tracker + Global Site Settings Control

### Tech Stack
- **Frontend:** HTML5, Custom CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL (`mysql2`)
